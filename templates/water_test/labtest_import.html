File format

The first row must hold these column headings, one result per row below it (extra columns are ignored):

Date · Sample · Technician · TDS · EC · pH · Salinity · Temp

  • Date can include a time (2025-03-14 09:30); with no time it's saved as 00:00. Day-first dates such as 14/03/2025 are accepted.
  • Technician must be one of: Dennis, Joy, Rodgers, Robinson, Virginia, Others.
  • A row is skipped if Lab Test already has the same sample name on the same day. Existing results are never changed.
  • Only impossible values are rejected (such as pH above 14); readings outside the standard's limits are saved as measured.
  • Up to 5,000 rows and 5 MB per file.
